# Sistem Informasi Kasir (Point Of Sales) Berbasis Web Untuk UMKM

Sistem informasi kasir berbasis web yang dikembangkan untuk membantu UMKM dalam mengelola transaksi penjualan, data menu, laporan pendapatan, serta monitoring aktivitas penjualan secara lebih praktis dan terstruktur.

## ✨ Fitur Utama
- 🛒 **Transaksi Kasir**  
  Memudahkan proses pemesanan dengan keranjang belanja, perhitungan total otomatis, input pembayaran, dan kembalian.
- 🍔 **Manajemen Menu**  
  Pengelolaan data menu seperti menambah, mengubah, menghapus, mencari, serta mengatur harga menu.
- 🧾 **Cetak Struk**  
  Mencetak bukti transaksi setelah proses pembayaran selesai.
- 📊 **Dashboard**  
  Menampilkan ringkasan transaksi dan informasi penjualan dalam bentuk statistik dan grafik.
- 📈 **Laporan Penjualan**  
  Menampilkan riwayat transaksi dan rekap pendapatan berdasarkan periode tertentu.
- 🏆 **Menu Terlaris**  
  Menampilkan daftar menu yang paling banyak terjual sebagai informasi pendukung dalam melihat performa penjualan.
- 📥 **Export Laporan**  
  Data laporan dapat diekspor ke format **Excel dan PDF** untuk kebutuhan dokumentasi dan pembukuan.

## 🛠️ Teknologi yang Digunakan
- **Backend:** PHP Native
- **Frontend:** HTML, CSS, JavaScript, Bootstrap
- **Database:** MySQL
- **Chart:** Chart.js
- **Export:** Excel & PDF
- **Environment:** XAMPP / Localhost
